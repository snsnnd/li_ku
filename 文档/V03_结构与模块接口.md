# V03 结构、模块接口与扩展

## 1. 范围

以4列×5层、单箱1 kg作为**设计输入**，不是载荷认证。V03保留V02的底托、钢销牵引和轻载曲柄滑槽思路，重做三轴传动及局部空间布局，不修改V02文件。

列距180 mm，列中心X=90/270/450/630；层面Z=200/295/390/485/580。料盒存储中心Y=65，搬运位Y=-78，名义箱体位移143 mm。独立IO箱位X=-150、Y=65、Z=200。

本版并没有把“全部改成齿条”误解为“所有承力件都改成塑料”。齿条/小齿轮可打印试验；框架、导轨、主连接板、承托方管、轴和防坠路径仍为金属或采购件。

## 2. 齿条与减速

| 项目 | 候选参数/表达 |
|---|---|
| 模数、压力角 | m=1.5，20° |
| 小齿轮 | 20齿、节圆Ø30、齿宽12 mm；渐开线轮廓离散采样，不是方齿示意图 |
| 齿条段 | 24齿距，113.0973355 mm；12 mm齿面、30 mm安装底宽 |
| 名义背隙 | 齿条与齿轮各减薄0.15 mm，合计0.30 mm；实打后需标定 |
| 分段数量 | X 9段、Z 5段、Y 2段 |
| 固定 | 每段4个M3安装孔，连续金属背板有对应攻丝底孔 |
| 轮毂 | 金属法兰夹紧轮毂；X为5 mm轴孔候选，Z/Y为8 mm减速器输出轴孔候选 |
| 减速 | X暂直接驱动，Z按10:1、Y按3:1减速器包络配置；供应商尚未确定 |

**不能把113.097 mm自行四舍五入成113 mm后复制拼接。** 接缝需要同时控制齿相、齿高、直线度和安装孔位置。导轨承担导向和力矩，齿条不是导轨；打印卡扣也不承担整机框架连接。

减速器包络并不代表里面的齿轮已详细建模，亦不表示已证明效率、寿命、背隙或安装孔符合某个品牌。选型后必须用实际图纸更新接口，再重新检查。

## 3. 模块接口

### A. 底座/长轴单元

- 三块金属底板宽度320/420/510 mm，接缝用金属连接板和螺栓；板面孔位与货架定位、固定关系已表达。
- X轴1050 mm整导轨与金属基准条仍为长轴单元，不能宣称已变成可任意拼接的精密轨道。
- 运输时优先拆货架列和搬运模块，长轴轨道尽量整体运输，避免每次重新校直。

### B. 独立货架列

- 每列四根独立立柱，不再与下一列共用立柱；后部各有金属抗剪板及间隔柱。
- 每列有178×170×6金属承载板。两处Ø6定位销分别进入圆孔和沿X方向的长孔，避免双圆孔过约束。
- 定位销轴线位于列中心X±75、Y=75；圆孔Ø6.2、长孔8×6.2是原型几何，不能当精密配合公差。
- 四处M6夹紧位置为列中心X±45、Y=20/130；底脚与承载板另用M5连接。孔的攻丝、旋入深度、预紧和工具空间仍需工程图复核。
- 料盒托板仍通过金属托角承重，不靠定位销或打印扣件承担全部重量。

### C. 升降搬运单元

- 双Z导轨、四滑块，承托方管保持金属；调整端挡及相机位置，避开全行程运动。
- 使用用户提供的完整ZDT_X42_L48Motor STEP，三轴均纳入后驱动板和接插件，而非42×42方块替身。
- 电机本体额定转矩、电压、质量未从CAD推定。模型里有3套同型电机参考，不表示用户已采购3台或三轴已选型通过。
- 独立钢安全轨与失电制动器候选布置在打印齿条之外。维护锁孔不等于已实现自动棘爪防坠。

### D. 取放头

- 原有竖直钢销、衬套、轴环、回位弹簧、打印曲柄/滑槽保留。
- 头部两处Ø3定位销对应一圆孔、一长孔，两处M3负责夹紧。定位和紧固分工，便于更换头部。
- Y轴改为双MGN9导向，并将承托臂、背板和末端导槽统一避让。
- 拆头前断电、固定升降机构、拔掉本地接插件。重新装头后复核销位和相机/工具外参，不把机械重复定位等同于免校准。

### E. 本地电源/控制盒

- 三个轴各设置一套随动盒，统一155×85×50 mm盒体和3 mm盖板。
- 电池候选空间85×65×42 mm，与ESP32/无线控制器区域隔开；有扎带穿槽、出线口和控制器侧散热槽。
- 四处M4固定位置在盒体中心X±60、Y±25，便于整盒拆下；盖板另用小螺钉固定。
- 电池、BMS、稳压器、保险及带锁扣防反插接头均需实际选型。模型没有把未选定插头假画成已完成接口。
- 目前不是热插拔设计。Z停稳且有独立机械支撑后，才允许拔下供电盒。

## 4. 受力和重量代价

新增随动电机、电池和接口会增加运动质量。初筛Z约7.3 kg、X约13.4 kg、Y约3.4 kg，均含货载/附件假设；最新细目见`engineering_checks.json`。

初始研究限速候选为X 12、Z 3、Y 5 mm/s，不是已测安全速度。按2倍转矩系数的初筛需求约为X 0.32、Z 0.34、Y 0.23 N·m，仍需对应转速下的实际电机曲线与减速器证明。

打印Z齿根的简化Lewis应力初筛接近30 MPa（含2倍系数），尚无所用打印机、材料、方向、温度及疲劳的允许值证据。因此**不能因为几何啮合通过，就直接带1 kg负载升降**。

整体约1.26×0.60×0.77 m、空机约67 kg，属于宽工作台结构原型。接头、台面锚固、最不利偏载和实际重量还需复核。轻量化应在接口验证后进行，不应通过取消防坠或随意减薄承力件解决。

## 5. 后续扩展边界

- 横向扩列：可复制货架列和齿条段，但还要延长/更换导轨、金属背板、底座及防护；不是加一个塑料齿条就完成。
- 纵向加层：要扩展立柱、Z导轨、安全轨、齿条和防护，并重新核算刚度、重心和制动。局部电池/电机模块有机会复用，但不是无限增高。
- 优先保留料盒外形、标签位置、头部接口和电源盒标准，避免每轮迭代连所有接口一起改。
