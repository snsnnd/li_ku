# V03 打样、验证与放行

## 1. 当前能做什么

可以先做局部打印和手动试装，不可直接批量制造、接电无人值守运行。所有报告保持`hardware_accepted=false`、`manufacturing_release_allowed=false`。

建议顺序：

1. 先打印一段齿条和一个小齿轮，配金属轮毂做低负载台架试验。验证中心距、背隙、接缝、拉脱、磨损和打印方向。
2. 打印一个带标签卡位的料盒、一块格口底托和一套取放头，配实际钢销、衬套、弹簧与舵机手动试装。
3. 打印一个电源空壳和盖板，用无电尺寸样块验证候选电池/控制板空间、扎带、接线、出线和拆盖，不先装裸电芯通电。
4. 做一列货架和IO窗口样件，验证手动提放、门行程、占位检测和遮挡。细长导槽横放打印，不能直接按装配姿态竖打。
5. 完成真实器件选型、独立防坠和安全回路后，才逐级开展受控运动试验。Z打印齿没有负载验收证据前，不做1 kg带载升降。

PETG仅是当前原型候选材料。切片壁数、填充、温度、材料含水、层间强度和长期蠕变应通过试块确定；不把一次成功切片等同于承载证明。

电源盖当前Ø2.8孔按钻孔定位使用：试样后扩至Ø3.4用于M3通孔；盒体Ø2.5导孔作M3攻丝底孔。先用空壳确认螺钉长度和夹紧，不把打印导孔直接当成已完成的标准螺纹连接。盖板螺钉不承担电池主固定，电池另用扎带/合适压条固定。

## 2. 软件证据的范围

- `static_validation.json`：实际B-rep初始装配干涉，不按“齿轮啮合”大范围忽略重叠。
- `tests.xml`：真实齿形跨齿距/拼接检查、三轴实际转动相位、打印尺寸、本地供电盒空间、模块定位、IO逻辑和视觉要求回归。
- `motion_validation.json`：所有库位及IO的离散运动检查。电机采用包含驱动板的保守包络；小齿轮采用保留轴孔的旋转外包络，啮合齿形另做真实实体检查。
- 运动采样覆盖Y取放/释放后退回/销孔间隙补偿、X在各层横移、Z沿各列与IO位置升降，以及内门升降行程。
- `delivery_audit.json`：逐件STEP回读、打印STL封闭性、整机实体数量/体积、报告指纹及码图来源核对。
- 这些不是连续碰撞检测、接触动力学、有限元、无线实机试验或安全认证。没有建模的全部螺钉、线束和工具空间不能因此算作已通过。

## 3. 必须补齐的采购和制造项

- 电机额定供电、接口、实际质量及对应转速下转矩曲线。
- Z 10:1、Y 3:1减速器的真实图纸、背隙、效率、寿命、输出轴和螺钉安装要求。
- 金属轮毂、夹紧结构、轴承支承与螺栓扭矩传递；不能靠打印孔与轴的摩擦力随便夹紧。
- 电池/BMS/充电器/保险/DC-DC、接插件额定电流和防反插。不得在参数未知时按候选包络直接下单。
- 具备独立保持/动态捕获能力的Z安全装置；确认正常失电、打印齿断裂且电机仍有电、控制器死机、编码器故障等工况。
- 精密导轨/型材的实际图纸、拼接能力、孔公差、安装面、模块定位配合和整机锚固。
- 门锁、门传感器、急停和独立安全回路；普通ESP32无线功能不能代替这些。
- 摄像头、焦距、照明和标定方法，以及实际料盒污损/偏摆/遮挡下的识别试验。

## 4. 复现

在项目根目录的Linux/WSL：

```bash
uv venv /tmp/opencode/asrs-v03-venv --python 3.12
uv pip install --python /tmp/opencode/asrs-v03-venv/bin/python -r cad/v03/requirements.txt
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/prepare_markers.py
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/asrs_v03.py --export
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 /tmp/opencode/asrs-v03-venv/bin/python -m pytest cad/v03/test_v03.py -q --junitxml=model/V03/tests.xml
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/verify_motion.py --step 12
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/engineering_checks.py
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/render_previews.py
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/export_contracts.py
/tmp/opencode/asrs-v03-venv/bin/python cad/v03/audit_v03.py --archive-stale
```

V03复用`cad/v02/asrs_v02.py`中的冻结几何工具，但不写V02目录。V03的指纹同时覆盖自身生成器、齿形脚本、V02依赖和用户电机STEP；改变它们之后必须重新生成全部证据。

不运行旧的SolidWorks原生转换脚本覆盖V02产物。本次优先交付STEP、STL与检查图，不宣称已经生成带运动配合的V03原生SLDASM。
