# V03 无线控制、独立IO窗口和视觉接口

## 1. 无线架构不是“无接线”

候选架构：调度主机 ↔ 无线 ↔ X/Z/Y本地节点，每节点含受保护成品电池、保险/开关、DC/DC、ESP32或同类控制器及本地驱动。

- 运动轨迹和步进脉冲由本地节点生成，不依靠Wi-Fi逐脉冲发送。
- 电机、限位、编码器、制动和舵机仍需本地短线；ESP32不能直接驱动电机绕组。
- 供电电压、峰值电流、驱动电平、舵机稳压和制动电源须以实际器件说明书为准。候选空间不代表任意电池都能装入或安全使用。
- 采用可拆卸、带保护的成品电池，不把临时裸电芯串联当成产品方案。充电器、BMS与电芯体系必须匹配；未选型前不提供充电参数。
- 天线需避开金属背板和电机，保留厂家要求的净空；当前几何没有经过RF、EMC或电池热安全测试。

**普通ESP32无线不是安全急停/安全门联锁。** 三个电池节点可能在主机断电后继续有电。要么保留独立硬接线安全链，要么采购并验证合适的安全级无线系统；不能默认Wi-Fi超时已经替代它们。

## 2. 本地控制要求

`cad/v03/control_contract.py`是可执行要求模型，**不是ESP32固件或无线协议栈**。

| 要求 | 候选逻辑 |
|---|---|
| 命令新鲜度 | 会话一致、序号不重复、命令年龄<150 ms |
| 心跳 | 年龄<250 ms；超时本地停车，禁止自动续跑 |
| 运动许可 | 已回零、本地急停正常、独立安全链正常、电池状态正常 |
| X/Z许可 | Y已完全收回；不允许未经验证的同时三轴运动 |
| Z许可 | 独立制动/防坠链就绪，不以电机保持力矩作唯一依据 |
| 低电量 | 在BMS硬切断之前拒绝新任务、停车并确认制动；阈值待电池选型 |
| 重启/掉线恢复 | 重新确认位置、占位和门状态，不能盲目接着旧命令运行 |

心跳250 ms不是安全认证值。制动延时、机械停车距离、驱动器故障、编码器丢失和电源跌落尚未实测。局部控制仍要有位置边界和独立硬限位。

**打印齿断裂时，电机仍可能有电。** 因此仅有“失电抱闸”不一定能捕获这一故障；还需要独立超速/下坠检测和具备动态捕获能力的装置，或适合的被动防坠器。当前橙色制动器只是占位，未完成这条安全链，禁止带载自动试验。

## 3. 独立取放窗口

- 左侧单箱交换站，坐标X=-150、Y=65、承托面Z=200，不占用4×5库位。
- 外罩有通向机外的开口和固定取放通道，外门位于通道内侧；它不是藏在完整外罩后面而无法使用的“假窗口”。
- 人从左侧手动提放料盒；机器人从前侧沿Y方向存取。当前是人工提放窗口，不是已完成的人机工学齐平抽屉。
- 内门采用竖直提升90 mm的结构预留，左右有槽形导向；固定上/下遮挡板与门搭接，避免从门上方绕入运动区。
- 预留有箱传感器。门铰链、锁扣、门位置检测、开门执行器及电气联锁尚未选型和实现。

### 入库顺序

1. 机器人退出窗口，Y收回并停稳，内门关闭且确认。
2. 才允许外门解锁；用户放入料盒。
3. 外门关好并锁定，确认窗口有箱、托盘空。
4. 内门打开并确认到位，机器人拉取料盒。
5. Y收回，确认料盒在托盘，关闭内门；随后才允许X/Z离开。

出库按相反的占位条件执行：托盘有箱、窗口空，外门必须先锁好。**外门开放时内门必须保持可靠关闭；头部未收回时不能关闭内门。** 不允许仅靠GUI上的“门已关”文字代替实体传感器和安全链。

## 4. 视觉：粗定位＋精定位，不是放弃坐标

建议流程：回零建立机器坐标 → 根据库存/库位粗定位 → 相机识别正确的箱ID与固定参考 → 校验图像质量和位姿 → 小范围修正 → 低速插销 → 位置/有箱反馈确认。

- 料盒标签在正面偏左，中心相对箱体为X=-36、Y=-61.2、Z=38 mm，避开中央牵引销和立板。
- 标记卡外形32×32 mm，留有白边。AprilTag36h11检测黑边正方形的边长为 **25.6 mm**；PnP尺度不能误填32 mm。
- 标签是可更换纸卡，不把黑白码直接做成粗糙3D浮雕。需哑光、平整、耐污，保持白边，实际打印100%不缩放。
- `model/V03/markers/`含BIN-001～020（ID0～19）、COLUMN-1～4（ID100～103）及IO-STATION（ID200），附A4 SVG/PDF和50 mm校准尺。
- **箱ID不等于库位坐标。** 料盒移动后ID不变，库存表要更新；固定列标记用于重装后的参考校准。
- 相机位于搬运模块前部，镜头前端到料盒标记的名义机械距离约66～209 mm。需选能在此距离对焦的镜头，不能只看分辨率。
- 摄像头内参、畸变、相机与工具外参、列模块与机器坐标、标签与牵引孔偏差都要标定。
- 建议初期采用1280像素级图像验证远端识别；最低像素、重投影误差、光照和置信度阈值需要实机确定。
- 要求模型只允许在回零/安全状态有效、图像新鲜、ID正确、已标定且停稳时尝试±2 mm以内修正；这不是已实现的识别或定位精度指标。
