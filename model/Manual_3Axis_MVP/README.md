# M01 手动三轴最小验证装置

**无电机、一个库位、原尺寸空料盒。只验证配合与手动存取，不验证1 kg承重，也不代表正式设备的金属导轨、防坠或电驱动方案已通过。原V03/V03.1不改动。**

## 先打这几个，不要一次全打

1. **[C01 导向轨试块](stl/C01.stl) + [C03 标称0.35间隙滑块](stl/C03.stl)**：端部套入，应能轻推全程移动，不强压、不锤入。
2. 对照 [C02 0.20试块](stl/C02.stl)、[C04 0.50试块](stl/C04.stl)。正式滑台采用0.35；若C03不适合，先校准切片补偿并反馈结果，再决定是否重出正式滑台，不能拿C04代替正式零件。
3. [P01 一段齿条](stl/P01.stl)、[P02 一个小齿轮](stl/P02.stl)、[P03 一个手轮连接套](stl/P03.stl)，配真实金属隔套和螺钉手动试装。
4. 上述通过后，再打印P08/P05/P07，先装一轴；确认顺畅后再做其余结构。

有 **30类打印文件，按清单共63件（含4个试块）**。这是保留完整尺寸料盒与三轴功能的最小功能版，不是耗材最少的齿条试片。按全部CAD实体体积和PETG密度粗算约3.16 kg；**这不是切片耗材预测**，实际用量取决于壁数、顶底层、填充和支撑，须以切片器为准。

## 结构和运动范围

| 项目 | 参数 |
|---|---|
| 底架 | 245×540 mm；纵梁每侧180/140/220三段 |
| 打印平台 | 所有STL最大轴向尺寸不超过245 mm，适配256 mm平台，仍需检查Brim和实际可用边界 |
| X手动行程 | -50～+50 mm |
| Z手动行程 | -40～+40 mm；钢锁销位置 -40/-20/0/+20/+40 |
| Y取放行程 | 143 mm |
| 料盒 | 保留110×120×60 mm箱体及原牵引孔 |
| 齿形 | 原V03模数1.5、20齿、20°；每轴2段113.097336 mm齿条 |
| 导向 | 打印斜面捕获式滑动导向，**不是MGN导轨的承载替代品** |

Z=0是底架纵梁上表面，纵梁下表面Z=-6；前横梁叠在纵梁上，横梁顶面Z=6。对准库位时两侧承托面Z=250。X/Z运动前必须Y完全收回。完整运动包络及基准见A02。

## 打印设置与方向

- 建议先用干燥PETG、0.4喷嘴、0.2层高做试块；设置仅作为起点，不是强度认证。
- 普通结构件可从4道墙、5层顶底、25%填充起试；齿轮齿条可提高壁数和局部填充，仍不得用于载荷试验。
- **STL已按推荐朝向摆正并移到正坐标，不要再全部自动“放平”。** P05/P06滑台及P07端挡为端面朝下，便于保持导槽截面。
- P01齿条背面朝下、齿朝上；不得单独把长度缩放到113 mm。X/Z/Y共用同一个打印齿条文件，不需要竖打齿条。
- P03连接套法兰下需要支撑，避免支撑接触轴孔；P17导销耳下需支撑，孔去毛刺后同轴检查。
- P19高234 mm，可加Brim竖打或侧放加支撑；P25长245 mm，Brim不能统一设8 mm，否则会超256平台。大件使用小Brim并先检查切片边界。
- 不缩放整件来修正间隙；优先校准流量、象脚和孔/轮廓补偿。齿条接缝不得有齿高台阶或错相。
- 两段齿条先松装，用小齿轮缓慢跨缝往返，确认齿距连续后再逐步锁紧；不要靠螺孔间隙强行拉齐齿相。
- PDF按标注尺寸读数；缩放打印后不要直接拿纸面长度当零件尺寸。打印实体以同编号STL为准，装配测量以STEP为准。

## 必须准备的金属件

具体规格、数量见五金清单，以下不能用打印件替代：

- 三根光滑金属隔套，外Ø6、内Ø4.2，L=40±0.1 mm；配M4x60螺钉作轴。手轮绕光滑隔套转动，不绕螺纹磨擦。
- M3/M4螺钉与螺母、垫圈；三根手轮轴各用两颗普通M4螺母对锁。
- M4x70半牙钢螺钉作Z定位锁销，另加保持螺母防脱；**不预紧到把锁耳拉弯**。
- M4x80半牙螺钉作牵引销；去毛刺、端部倒钝，导向处优先光杆。
- 四个工作台夹具；底架不夹紧时禁止升Z。

**注意长度不能随便替换：**底架拼接板使用M3x10；X底座、横梁和库位底脚使用清单中的M3x12。换成长螺钉可能穿出底面顶住工作台。托盘/库位的8颗M4为90°沉头螺钉，头径≤9 mm，必须齐平或低于滑动面；普通圆柱头不能替代。

## 手动存取与安全边界

1. 夹紧底架。空盒置移动托盘，牵引销插入料盒耳孔，Y收回。
2. 调整X/Z。**拔Z锁销之前先手托升降平台**，慢转Z手轮；到位后插入钢锁销并加保持螺母，才允许松手。
3. X=0、Z=0对准库位，确认两承托面等高，缓慢转Y手轮推入空盒。
4. 牵引销手提至少14 mm，确认离开耳孔，保持提销状态再收回Y头。取回按反序进行。

禁止放物料/砝码、验证1 kg承重、用电钻驱动、加长手柄强行过卡点，或把手放到升降台下。Z销是**手动定位锁**，没有自动捕获功能；不能代替防坠器或让机构无人保持地自由下降。

工程图中H开头的STEP是采购参考包络，**没有对应打印STL**。打印导向的配合、齿条磨损与寿命仍需实物检查。

## 文件核验

- `validation.json`：实体/网格/打印尺寸、静态和121个离散运动位姿，以及关键支承贴合面检查；不含全部框架螺钉头及工具空间的连续碰撞验证。
- `tests.xml`：几何、导向捕获、轴向游隙、底架螺钉长度及螺母通道等回归。
- `delivery_audit.json`：图纸、模型、报告指纹与文件完整性；所有实物/载荷放行均为false。
- `stl/`的30个文件与PDF图号一致。打印数量不得按文件数猜测，以CSV为准。

## 从源码复现

项目根目录的生成器：`cad/manual_mvp/`。安装其 `requirements.txt` 后依次执行：

```bash
python -B cad/manual_mvp/manual_3axis.py
python -B cad/manual_mvp/drawings.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -B -m pytest cad/manual_mvp/test_manual.py -q -p no:cacheprovider --junitxml=model/Manual_3Axis_MVP/tests.xml
python -B cad/manual_mvp/verify_manual.py
python -B cad/manual_mvp/export_compatibility.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -B -m pytest cad/manual_mvp/test_compatibility.py -q -p no:cacheprovider --junitxml=model/Manual_3Axis_MVP/viewing/compatibility_tests.xml
python -B cad/manual_mvp/publish.py
```

图纸生成默认读取WSL可见的Windows黑体，嵌入PDF子集；其他环境可通过 `MANUAL_CJK_TTF` 指向可嵌入的中文TTF。未发布原生SolidWorks运动配合装配文件，STEP可查看和测量，STL用于切片。
