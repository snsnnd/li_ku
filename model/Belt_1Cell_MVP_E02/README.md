## 1kg是不是轻载？

**就货物本身而言，是轻载。** 但它只表示货物净重；Z还要搬动托盘、导向平台、电机、释放机构和料盒。完整运动质量与扭矩估算见优化对比，不能将电机只按9.8N货物重力选型。托盘悬臂、摩擦、加减速和异常掉落也需考虑。

优化目标是减少无效移动质量、悬臂和齿条调试难度，不是把1kg包装成已验收载荷；也没有擅自提高目标承重。

货物竖向重量主要由托盘/金属方管及Z升降结构承受；Y同步带和轻连接臂负责推拉，不是把整个货物悬挂在薄连接臂上。

## 打印/采购边界

- 只打印`stl/`中`process=print`对应分件，按CSV数量；不要把整机一次打印。
- 带轮、惰轮轴承/肩轴、带夹、承力板、方管、丝杆、螺母桥和维护件必须是合适金属件，不能打印替代。
- 采购带轮/同步带是光滑有效包络，夹齿只示意节距。**它们不是GT2制造齿形，也不是已经选定供应商的产品。**
- 张紧器±/单向2mm是调整空间，不是要求把皮带拉长4mm。15N预紧只是估算例，不能作为操作张力。
- 采购BOM记录CAD实例数量，全部型材角码、PC门板保持、线束和非建模连接五金仍需补选。补充清单列出具体边界。
- 图纸是设计评审图，未完成公差、实际螺纹、厂商尺寸、有效啮合、工具可达性和工艺签审，不能直接视为加工放行图。

## 仍不能直接上电带载

同步带降低所需驱动扭矩，但张紧会增加电机轴的径向力，必须核对实际ZDT轴承/轴端能力。还需确认：

1. 实测电机质量、扭矩-转速曲线、电压/电流和温升；真实驱动带轮夹紧及轴向保持。
2. 实带规格/齿形/张力、金属带夹拉脱、惰轮轴承/肩轴、张紧锁紧、板件刚度和线束全行程。
3. 丝杆/螺母/轴承配合、预紧、横销定位套强度和寿命；全部紧固、压缩套和台面锚固。
4. **独立自动防下滑装置、实际限位/门禁/急停和电气保护，仍未完成选型/实施。** 第二螺母、低导程丝杆和手动维护销不能替代自动防坠。
5. 自动存取固件未提供；释放舵机、IO门和传感器仍需实际选型与接入。

模型维护销默认插入。Z运动前必须可靠卸载、拔销并确认状态。先完成安全措施，再组织空行程/空盒及分级加载试验；**目标1kg不等于允许直接1kg带载运行**。
