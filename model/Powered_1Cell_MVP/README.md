**3台现有同款ZDT电机；X/Y齿条，Z金属TR8x2丝杆；目标货载1kg。不是无电机的手动M01，也不是20库位V03.1。**

## 与旧版本的区别

| 项目 | E01 |
|---|---|
| 电机 | 用户完整ZDT参考STEP，3台，分别驱动XYZ |
| 库位 | 1个货位+独立IO，1只原尺寸料盒 |
| X/Y驱动 | m1.5、20°、20T打印齿轮/齿条，金属夹紧轮毂，直接驱动 |
| Z驱动 | 金属TR8x2、双金属螺母、顶端推力/径向支承、下浮动支承、候选5x6联轴器 |
| 导向/承力 | 金属微型导轨、3030、金属螺母桥及托盘方管，不使用手动版打印滑轨承重 |
| 行程 | X180mm、Z95mm（层面200..295）、Y取放143mm |
| 底板 | 连续金属610×650×6；X电机后移，避免与丝杆下支承相撞 |
| 供电 | 有线机械方案；已去掉旧无线电池包和两套减速器 |
| 自动化 | 未交付可运行固件，急停/门禁/限位安全链尚未实现 |

坐标基准：底板下表面Z=0，上表面Z=6。模型默认停在货位层，**维护销处于插入状态**。任何Z运动前必须可靠卸载、拔销并确认状态。

## 打印与采购

- 打印只用`stl/`内分件，数量见[打印清单](打印清单.csv)；同编号STEP在`parts/`。不要将整机STEP一次切片打印。
- [采购与金属加工清单](采购与金属加工清单.csv)、[完整模型BOM](BOM.csv)、[采购补充与未选型项](采购补充与未选型项.md)。
- `process=print`才是打印件。金属丝杆、螺母、轮毂、轴承壳、承力桥和维护件**禁止打印替代**。
- STL只完成几何落床和网格检查，不等于切片支撑已审核。先核对实际打印机、材料、孔补偿和悬垂。
- 采购BOM是CAD实例数量。部分型材连接、轴承叠层、底座/齿条/IO/托盘连接五金未逐颗建模，详见补充清单；不能声称已是可直接装配的完整生产套件。

## 1kg是目标，不是承重合格证

本交付是**带真实电机外形的机械设计与几何验证**，不是已完成的自动运行设备。尚未确认：

1. 电机运行扭矩曲线、供电/电流/温升、实测质量和实际轴/盲孔尺寸。
2. 丝杆、轴承、横销、定位套、联轴器和自制轮毂的配合、公差、预紧、强度与寿命。
3. 独立自动制动/防下滑装置。第二螺母和手动维护销都**不是自动防坠器**，也不宣称丝杆能可靠自锁。
4. 所有连接件长度、啮合、防松、工具可达性及台面锚固；打印齿形/料盒的蠕变及寿命。
5. 限位实际安装/触发、急停/门禁/保护接地/短路保护和故障安全；运动线束及固件。

**这些项目完成前，不允许直接上电带载运行。** 几何无干涉、理想受力估算或STEP有效，均不能代替实物试验和安全验收。

## 复现

依赖见`cad/powered_mvp/requirements.lock.txt`（生成时环境）；入口：

```sh
python -B cad/powered_mvp/validate_powered.py --motion --export
python -B cad/powered_mvp/deliver_powered.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -B -m pytest cad/powered_mvp/test_powered.py -q -p no:cacheprovider --junitxml=model/Powered_1Cell_MVP/tests.xml
python -B cad/powered_mvp/publish_powered.py
```

旧的`model/V03_1/`和`model/Manual_3Axis_MVP/`不因本版重新生成。
