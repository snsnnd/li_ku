## 新架构

```text
固定底座：ZDT A + ZDT B，CoreXY双层独立开口带
   └─ 双侧Y导轨/四长块 + 双金属箱梁横梁
        └─ 双X导轨/四长块 + 金属承载小车
             └─ 第三台ZDT + TR8x2金属丝杆Z塔
                  └─ 固定钢双叉，直接托起料盒
```

- A/B两台电机都不移动。一台不再独占X或Y：当前带路约定`A=ΔX+ΔY，B=-ΔX+ΔY`；每转40mm带位移。实际接线正负/协调轨迹未验证，不能直接用原独立XY指令或雕绘仪BIN。
- 两根500×40×60×4金属箱梁代替雕绘仪轻横梁；Y和X各四个长滑块承担塔架和货叉的重量/力矩。皮带不是竖向承载件。
- 默认平面小车(90,-140)，工作X=-90..90、Y=-140..3；一货位中心(90,158,380)，IO(-90,158,293)。
- IO层面抬高8mm，给叉进入预留空间，避开升降下轴承/止挡。新名义层差87mm，另设叉面低于货位8mm的进入位和高于4mm的取货位；实际Z验证范围285..384mm，不能沿用E02硬限位设置。
- 料盒保留110×120×60外形，但去掉牵引眼；固定双叉取放无需独立Y电机、皮带推拉头、牵引销或释放舵机。新旧料盒/货位接口不得混用。
- 货位外侧两条金属承托轨，中间留叉道。存货时盒落在轨上，叉再下降退出；取货先进入、微升、退出。几何余量不是已验证实物安全距离。
- **插叉后不能横向跨库位。** X/Z穿梭应在Y=-140退出通道进行；Y进入/退出只在对准货位或IO后执行。验证针对这些合法存取路径，不声称整个XY矩形任意姿态都无障碍；这项控制联锁尚未实现。

## 相比E02的取舍

**收益：** 两台平面电机固定在底部，上部驱动/释放机构减少，取放改为直接承托，带路和维护集中。

**代价：** Y也要搬动整套Z塔；横梁/底部支承和占地增加，A/B控制耦合。底板660×680×8，本版**不宣称比E02总体更轻、更小、最优或已能承重**。质量、扭矩和理想叉挠度只作方案筛查，详见估算报告。

参考`D:\tmp\【大鱼DIY】雕绘仪 EP V3.0 全套资料`的拓扑，不沿用其轻笔架承重件；其采购表与STEP尺寸不一致，未混用下料。参考资料未改、EXE未运行、BIN未刷写。

## 当前完成与未完成的边界

完成的是架构重构、参数化BRep装配、平面开口带长/映射、几何碰撞/存取过程和导出一致性检查。报告中的“通过”只指相应离散几何检查。

**以下仍需继续工程化，不可据模型直接整套加工/上电：**

1. A/B金属带夹的真实GT2齿形压板、螺纹张紧/锁紧、固定惰轮的可调接收接口和拉脱/刚度校核。当前只给出端点和空间包络，未完成可制造的完整张紧细节。
2. 采购带轮的实际下轮毂夹紧、轴向保持；上层B轮毂与现有轴约6mm啮合的可行性、肩轴/轴承内圈隔套和完整保持叠层。
3. 实际电机运行曲线、供电/电流/温升、实测质量和皮带预紧导致的轴承径向力。不能从外形或保持扭矩推出满足要求。
4. 导轨/滑块额定力矩、双梁平面度、塔脚/端板、货叉根板/焊缝、货位承托连接、全部紧固/盲孔/工具空间、公差和台面锚固。
5. 金属Z轴颈/螺母/推力栈/横销定位套配合与预紧，独立自动防下滑和维护支撑验证。
6. 实际限位开关/触发片、门禁/门锁、急停/断能/接地/短路保护、柔性线束、A/B/Z协调及自动存取固件。

**1kg是轻货载，但货叉、平台、电机及塔架自重远不止1kg。目标载荷不是安全工作载荷。** 第二螺母、低导程丝杆、手动维护销都不能替代独立自动防坠。模型默认维护销插入；Z运动前要有可靠支撑、拔销并确认。

只打印`process=print`且在`stl/`中的分件；金属叉、箱梁、小车板、丝杆、螺母桥、带夹、轴承/带轮禁止打印替代。STL只完成落床/闭合检查，切片支撑、孔补偿和打印材料性能仍需实测。
